# Notebooks

Research notebooks from building the corpus and the graph, kept without outputs. They need the source PDFs, the
databases and API keys, none of which are in this repository.

Each notebook starts with a small bootstrap cell: it switches to the repository root and puts `pipeline/`,
`third_party/dolphin/` and `tests/` on the import path, so the notebooks behave as they did when they sat at the
root.
